# Screenshots for the 8D87 lighting pull request

An orphan branch, carrying nothing but these images. They are referenced from the
body of the lighting pull request; keeping them here means they never appear in a
diff a reviewer has to read.

Taken on HP OMEN MAX 16-ak0098nr, board 8D87, BIOS F.07, EC 40.38.

- `per-key-editor.png` — the measured per-key editor. 108 keys at the positions the
  keyboard reported, with the light bar's four zones below them in the same
  selection space. Painted red with the upper-left block left green.
- `effects-and-light-bar.png` — the keyboard effects card, rendered by the device's
  own controller, and the light bar card with its colour, brightness and animation
  controls.
